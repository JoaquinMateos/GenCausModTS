# Running the audited benchmark on the GTX 2080 / RTX 2080 Ti

The audit changed the temporal generators, the Voronoi same-time graph, the
static-effect loaders, several metrics and the EMA setting.  A pre-audit row is
therefore **not** compatible with a new row: do **not** run the new code on top
of `outputs/` or `outputs_shared/`.

## Outputs: archive, do not append

`scripts/run_2080.sh` automatically renames an existing tree:

```
outputs        -> outputs_pre_audit_<date>
outputs_shared -> outputs_shared_pre_audit_<date>
```

and then creates fresh `outputs/` and `outputs_shared/`.  Use the script (or
perform the same rename by hand).  The resume guard would otherwise refuse to
append because the code revision changed; forcing it would mix two protocols in
one table, which is exactly what the audit was meant to prevent.

## One command

```bash
cd gcmts
CUDA_VISIBLE_DEVICES=0 bash scripts/run_2080.sh
```

`run_full_benchmark.py` inherits `CUDA_VISIBLE_DEVICES` by default. You can
also pass `GPUS=0` (or `GPUS=0,1` for round-robin over two cards). Do not rely
on an old `--gpus 1` default: it was removed because it silently overrode the
parent’s `CUDA_VISIBLE_DEVICES`.

Environment overrides:

```bash
SEEDS=10 REPLICATIONS=100 JOBS=8 bash scripts/run_2080.sh
SKIP_DOWNLOAD=1 bash scripts/run_2080.sh          # datasets already present
```

Requirements: CUDA, `uv`, and about **25-35 GB free** (canonical static data,
the 1.4 GB ACIC archive, and the synthetic train/eval pools including the grid).  If the machine has no LaTeX installation, the final
`make_paper_tables.py` still writes the `.tex` files; compile them on the
writing machine.

## What the script does

1. `uv sync --extra dev --extra real` (xarray/netCDF4/anndata etc. for the real
   loaders). The script passes `--seeds <count>` (not a list) and
   `--data-source pool` to the orchestrator.
2. Archives old outputs.
3. Downloads IHDP, Twins, Jobs, News, ETTh/Jena/COVID/energy panels, and the
   ACIC 2018 Zenodo mirror; converts 100 ACIC replications.
4. Materialises the synthetic pools for all 20 CRL benchmarks, the 18 grid configs and 10 seeds (`--with-grid`). The full run uses `--data-source pool`.
5. Runs every benchmark (CRL A.1–A.17 + A.1b, B–D; CTEE temporal; IHDP/ACIC/
   Twins/News; real cohorts LaLonde/Jobs/NHEFS/Oregon; SDD; adjacent; real
   external validity; 18-problem grid), then regenerates the LaTeX tables.
6. Re-runs the table generator (idempotent).

The default protocol is **EMA λ=0.99 uniformly**, KL warm-up 50 epochs, a common
2000-epoch CRL budget, a shared per-seed evaluation batch, and the corrected
metrics.  The orchestrator suppresses wall-clock times when `--jobs > 1`; the
paper currently leaves the time column as `--`.  For real timings run the
individual steps with `--jobs 1 --keep-timing` on an idle machine.

## Canonical static datasets

| Benchmark | File | Source |
| --- | --- | --- |
| IHDP | `data/semi_synthetic/ihdp_npci_1-100.{train,test}.npz` | fredjo.com (auto) |
| Twins | `data/static/twins.csv.gz` | `mlforhealthlabpub` Bitbucket mirror (auto) |
| Jobs | `data/static/jobs_{train,test}.npz` | fredjo.com (auto) |
| News | `data/static/news/` | fredjo.com `NEWS_csv.zip` (auto) |
| ACIC 2018 | `data/acic/<ufid>/{x,z,y,mu0,mu1}.csv` | Zenodo record 19175621 (auto) |
| CPS | `data/static/cps.csv` | **manual**: not publicly mirrored by the CFRNet authors; request the file and place it with columns `t, yf, ycf, mu0, mu1` + covariates |

ACIC outcomes are standardised per replication by the factual mean and standard
deviation, so PEHE/eps_ATE are reported in standard-deviation units.  Its
`mu0/mu1` are the realised potential outcomes released by the mirror, not
noiseless surfaces; this is stated in the table caption.

## Expected duration

On one RTX 2080 Ti with `--jobs 8` the full run is dominated by the five static
panels, the 18-problem grid and the Voronoi/Causal3DIdent suites; expect
multiple days.  The orchestrator is resumable by default: if it is interrupted,
rerun the same command (without `--force`) and it skips completed `(case, seed)`
rows.  Because the protocol is now clean, the resume guard will accept the same
configuration/revision.

## After the run

```bash
cd gcmts
uv run python scripts/make_paper_tables.py \
  --shared-dir outputs_shared --outputs-dir outputs --latex-dir ../latex
cd ../latex && latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

Check `outputs/logs/errors.log` for failed steps.  The audit appendix
(`latex/appendix/I_audit.tex`) is the reference for what is being regenerated
and why.
